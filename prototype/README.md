# Design prototype

A prototype of the proposed additions to the current site, for review. It is not part of the live site.

The pages are the existing homepage and CWARE Connect page, with their design and copy unchanged. Three things are added:

- product illustrations for CWARE Recruit and CWARE Connect
- a strip for client logos
- a client testimonial

Files:

- `index.html` is the homepage.
- `connect.html` is the CWARE Connect page.
- `screenshots/` holds before-and-after comparisons and full-page captures.

Open either HTML file directly in a browser. Each one is self-contained and works offline. Both are set to `noindex`, so search engines ignore them if they are ever uploaded.

The product screens are illustrations built in HTML, and the client logos and testimonial are placeholders. They will be replaced with real material once it is supplied and approved.
