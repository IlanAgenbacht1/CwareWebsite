# Design prototype

A working prototype of the proposed redesign, for review. It is not part of the live site.

- `index.html` is the homepage.
- `connect.html` is the CWARE Connect product page.
- `screenshots/` holds before-and-after comparisons and full-page captures.

Open either HTML file directly in a browser. Each one is self-contained, with its styles, font and logo inlined, and set to `noindex` so search engines ignore it if it is ever uploaded.

Product screens are illustrations built in HTML, and client logos and the client quote are marked placeholders. Both get replaced with real material once it is supplied and approved. All prices and product descriptions come from the current site.
