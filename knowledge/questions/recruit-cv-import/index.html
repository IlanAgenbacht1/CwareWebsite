Question

Can CWARE Recruit import our existing CVs?

Yes. Recruit captures candidate information from PDF and Word CVs, and supports verified bulk CSV import for existing candidate data. Recruiters review and correct the records.

CV capture

Education, work history, skills, salary and notice period are captured into a structured record for review.

Database migration

Bring a representative export of the current database so field mapping and data quality can be assessed.

Submission output

The platform generates formatted Word CVs using internal, external and white-label templates.
